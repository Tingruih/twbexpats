## Gumbo

## 摘要

GUMBO（Grand Unified Master Baseball Object）即時資料流提供標準化的 JSON 回應，每次更新時都會摘要所選比賽的完整狀態。與先前的 MLBAM 即時賽事資料流不同，每次建立 GUMBO 物件時都能取得完整的比賽資訊，而不是採取增量更新的方式。對使用者的好處包括：

1. 不需要在本地端維護比賽狀態，也不需要根據一連串訊息逐步組合出完整的比賽資料；由於每個 GUMBO 物件都會包含整場比賽完整且最新的資料集，因此消除了手動重建比賽資料的需要；

2. GUMBO 遵循真正的 JSON 標準，不像先前的 MLBAM 即時資料流那樣是高度客製化且僵化的格式；

3. GUMBO 可透過 Websocket（推播，1-2 秒）監聽取得，也可透過 Stats API（拉取，12 秒）取得，讓使用者能在任何時間點使用實際的正式環境資料進行開發，而不需要依賴手動輸入之測試資料的排程遞送。

若要透過 Stats API 存取特定比賽的 GUMBO，請將特定的 game_pk 代入以下基礎 URL：

取得目前比賽狀態：https://statsapi.mlb.com/api/v1.1/game/{game_pk}/feed/live

1. 取得比賽中特定時間點的狀態：https://statsapi.mlb.com/api/v1.1/game/{game_pk}/feed/live?timecode=yyyyymmdd_#######，其中 time_code 的值取自該場比賽更新時間戳記清單：https://statsapi.mlb.com/api/v1.1/game/{game_pk}/feed/live/timestamps

2. 已淘汰（DEPRECATED）：GUMBO 可透過已驗證的 ActiveMQ 資料流取得。訊息主題名稱將為：mlbam.feed.2.0.game.state.full.{venueld}

### GUMBO 概觀

GUMBO（Grand Unified Master Baseball Object）即時資料流提供標準化的 JSON 回應，每次更新時都會摘要所選比賽的完整狀態。與先前的 MLBAM 即時賽事資料流不同，每次建立 GUMBO 物件時都能取得完整的比賽資訊，而不是採取增量更新的方式。

##### 對使用者的好處：

- 不需要在本地端維護比賽狀態，也不需要根據一連串訊息逐步組合出完整的比賽資料；

- 由於每個 GUMBO 物件都會包含整場比賽完整且最新的資料集，因此消除了手動重建比賽資料的需要；

- GUMBO 遵循真正的 JSON 標準，不像先前的 MLBAM 即時資料流那樣是高度客製化且僵化的格式；

- GUMBO 可透過 Stats API（拉取，12 秒）取得，讓使用者能在任何時間點使用實際的正式環境資料進行開發，而不需要依賴手動輸入之測試資料的排程遞送。

若要透過 Stats API 存取特定比賽的 GUMBO，請將特定的 game_pk 代入以下基礎 URL：

• 取得目前比賽狀態：https://statsapi.mlb.com/api/v1.1/game/{game_pk}/feed/live

• 取得比賽中特定時間點的狀態：https://statsapi.mlb.com/api/v1.1/game/{game_pk}/feed/live?timecode=yyyymmdd_#######

o 其中 time_code 的值取自該場比賽更新時間戳記清單：

https://statsapi.mlb.com/api/v1.1/game/{game_pk}/feed/live/timestamps

• GUMBO 目前有五種可用的 hydrations：

credits：此 hydration 會填入一個 credits 陣列，列出任何事件發生時記錄在案的打者與投手。此 hydration 的主要目的是追蹤同一個打席（ab）中途發生的投打替換。

alignment：此 hydration 會填入一個 defense 物件，列出 liveData->plays->allPlays 陣列中每個賽事事件（play event）的每個守備位置，以及一個 offense 物件，內含打者與跑者資訊（若壘包上有人）。

flags：此 hydration 會在需要額外描述性識別資訊時，於 liveData->plays->allPlays 物件中填入一個 flags 陣列。

officials：此 hydration 會填入一個 officials 陣列，內含每個賽事事件（play）中裁判的配置。

o preState：此 hydration 會填入一個 officials 陣列，內含每個賽事事件（play）中裁判的配置。

例如：https://statsapi.mlb.com/api/v1.1/game/566615/feed/live?hydrate=credits,alignment,flags,officials,preState
